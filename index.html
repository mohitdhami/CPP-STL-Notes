📦 Containers & Vectors <vector> <algorithm> <limits>

A container holds a collection of same-type elements with add / remove / access ops. STL gives you vector, array, list, map, set… — each tuned for different needs.

A vector is a dynamic array that resizes itself. Benefits over raw arrays: grows/shrinks dynamically, bounds-checked access via at(), easily copied/resized.

Header: #include <vector>  |  Key methods: push_back, pop_back, size, front, back

Declaration — 1D & 2D

// 1-D
vector<int> v;
vector<int> v2(size, val);        // size cells filled with val
vector<int> v3{1,2,3,4,5};
vector<string> fruits{"Apple","Banana","Orange"};

// 2-D
vector<vector<int>> m;
vector<vector<int>> m2{{1,2,3},{4,5,6},{7,8,9}};
vector<vector<int>> mat(m, vector<int>(n, val)); // m rows x n cols

Traversing

// index loop
for (int i = 0; i < (int)v.size(); i++) cout << v[i] << " ";
// range loop
for (auto x : v) cout << x << " ";
// iterator
for (auto it = v.begin(); it != v.end(); ++it) cout << *it << " ";
NOTE: end() points past the last element — it does not point to a valid element. Always compare with != end().

Method reference

size() / max_size() / capacity()elements count / max possible / currently allocated slots. For 2D: m.size()=rows, m[0].size()=cols.
push_back(x) / pop_back()add/remove from back in amortised O(1).
front() / back()first / last element.
begin() / end()iterators to first / past-last element.
find(b,e,val)it = find(v.begin(), v.end(), 4); → iterator to first match or v.end(). Check it == v.end() for “not found”. *it = value, it - v.begin() = index. You can subtract iterators: it2 - it1 = distance.
sort(b,e,comp?)sort(v.begin(), v.end()) ascending; sort(v.begin(), v.end(), greater<int>()) descending. Strings sort by ASCII: "bC78ip" → "78Cbip".
insert(pos,val) / erase(pos) / reverse / clear / resizev.insert(v.begin()+i, val); v.erase(v.begin()+2) (takes iterator, avoid on huge vectors); reverse(s.begin(), s.end()); clear() empties but keeps capacity; resize(n) fills new slots with 0.
count / min,max_element / numeric_limitscount(v.begin(),v.end(),2) (<algorithm>, chars/digits only — not substrings); *max_element(a.begin(),a.end()); numeric_limits<int>::max() from <limits> — portable INT_MAX.

Custom comparator (sort)

bool desc(int a, int b){ return a > b; } // true ⇒ a before b
sort(nums.begin(), nums.end(), desc);

// sort pairs by first, then second
bool cmp(const pair<int,int>& a, const pair<int,int>& b){
  if (a.first != b.first) return a.first < b.first;
  return a.second < b.second;
}
vector<pair<int,int>> p{{5,2},{2,9},{1,9},{5,1}};
sort(p.begin(), p.end(), cmp);
Rule: comparator returns true ⇒ first arg comes before second. Return false ⇒ opposite order.

resize() — 1D & 2D pattern from notes

vector<int> v1; v1.resize(5);                    // {0,0,0,0,0}
vector<vector<int>> v2; v2.resize(5, vector<int>(5)); // 5x5 zeros

🔤 Strings, Arrays & Numbers <string> <utility> <sstream> <cctype>

Case transform & swap

transform(s.begin(), s.end(), s.begin(), ::toupper); // lower → UPPER
transform(s.begin(), s.end(), s.begin(), ::tolower); // UPPER → lower
toupper('a'); tolower('Z');                          // single char
swap(s1[x], s1[y]);  // <utility> — works for int arrays too

string ⇄ int

string s = "123"; int n = stoi(s);   // <string>; throws invalid_argument if bad
string t = to_string(456);             // int → string
try { stoi("abc"); } catch (const invalid_argument& e){ cout << e.what(); }

Reverse / compare / substr

reverse(s1.begin(), s1.end());          // "Hello" → "olleH"
s1.compare(s2); // 0 ⇒ equal  |  (s1 == s2) works too
if (str1 <= str2) { /* dictionary order; UPPER < lower */ }
string a = str.substr(pos, len);        // substr(pos,len)
string first = str.substr(0, str.size()/2);
string second = str.substr(str.size()/2);
Concat gotcha: string s = "" + 'a'; // ERROR and "" + s.back() fail (char ≠ string). Do: string x=""; x = x + s.back(); or use append().

Parsing with istringstream

#include <sstream>
string input = "42 3.14 hello world";
istringstream iss(input);
int n; double d; string w1,w2;
iss >> n >> d >> w1 >> w2;  // 42, 3.14, hello, world
// reuse:
iss.clear(); iss.str("");

Char / type helpers

isalnum(c) / isdigit(c)<cctype>. Non-zero ⇒ true. Only pass a char, not a string: isdigit(str[1]).
typeid(x).name()<typeinfo> — debug helper: typeid('a').name() // c.
abs / fabs / min / max / INT_MIN / INT_MAXabs(int) (<cstdlib>), fabs(double) (<cmath>). ⚠️ abs(s1.length()-s2.length()) errors (size_t!) — hoist to int first. min(a,b)/max(a,b); INT_MIN/INT_MAX from <climits>.
char→int digit trickint d = ch - '0'; // '5'→5 (implicit cast). (int)ch gives ASCII 53 — wrong!

🥞 Stack, Queue & Linked Lists <stack> <queue> <list> <forward_list>

Stack — LIFO

stack<int> st;
st.push(5); st.push('A');
st.pop();              // no return!
int t = st.top();      // peek
st.empty(); st.size(); // cast: (int)st.size()

Queue — FIFO

queue<int> q;
q.push(1); q.push(2);
q.pop();
q.front(); q.back();
q.empty(); q.size();

std::list — doubly linked

#include <list>
list<int> L;
L.push_back(10); L.push_front(5);
L.pop_back(); L.pop_front();
L.insert(it, val); L.erase(it);
L.size(); L.empty();
for (auto it=L.begin(); it!=L.end(); ++it) cout << *it << " ";

std::forward_list — singly linked (lighter)

#include <forward_list>
forward_list<int> F{30,20,10}; // push_front only!
F.push_front(5); F.pop_front();
F.insert_after(it, 25); F.erase_after(it);
F.remove(20); F.unique(); F.sort();
// insert at end via before_begin():
auto it = F.before_begin(); // then insert_after
list = 2 pointers/node + bidirectional; forward_list = 1 pointer/node, forward-only, no push_back() — but faster & leaner.

🗺️ Hash Map & Hash Table <unordered_map> <map>

“Hash Map performs insert / delete / traversal in constant time.” It maps unique key → value.

unordered_map (Hash Map)map (Balanced BST / Red-Black)
Hash table, unsorted, avg O(1) insert/delete/findSorted by key, O(log n) insert/delete/find, lexicographic order
unordered_map<string,int> table;
table["C++"] = 1;                                  // easiest insert
table.insert(make_pair("C++",1));
table.insert({"C++",1});
unordered_map<int, vector<int>> hm;
hm[0].push_back(1); hm[0].push_back(2); hm[1].push_back(3);

table["C++"]; table.at("C++");                     // fetch
table.find(key) == table.end();                    // existence?
table.count("C++"); table.size(); table.erase("C++");

unordered_map<string,int>::iterator it;
for (it = table.begin(); it != table.end(); ++it)
  cout << it->first << ": " << it->second << "\n"; // first=key second=value
NOTE: re-inserting an existing key overwrites it. Fresh keys default to '\0'/0 (int/char) or "" (string) — so if (mp[k]=='\0') detects “never set” (avoid comparing directly to 0 to dodge real-zero confusion).
Dedup trick (order-preserving): hash-map + array removes duplicates without sorting — same idea as the unordered_set snippet in Sets.

⛰️ Heap & Priority Queue <queue> <vector> <functional>

A priority_queue is a container adapter over a heap — O(1) peek at min/max, O(log n) push/pop. Default = max-heap.

priority_queue<int> pq;               // max-heap
pq.push(10); pq.push(20); pq.push(30);
while(!pq.empty()){ cout << pq.top() << " "; pq.pop(); } // 30 20 10

priority_queue<int, vector<int>, greater<int>> mn; // min-heap
priority_queue<pair<int, vector<pair<int,int>>>> cont; // nested example from notes

Max-heap

Parent ≥ children, root = max. Array layout: children of i at 2i+1, 2i+2. Insert/delete O(log n), peek O(1). priority_queue<int> pq builds one by default.

Min-heap

Parent ≤ children, root = min — ideal for Dijkstra. Duplicates are kept (pop extras as needed).

// custom comparator → min-heap
struct Cmp {
  bool operator()(const int& a, const int& b){ return a > b; }
};
priority_queue<int, vector<int>, Cmp> pq2;
// 2nd template param = underlying container (default vector), 3rd = comparator (default less → max-heap)
operator() overloading = “function-call operator” — the queue calls it to order elements.

🍃 Sets <set> <unordered_set>

set = unique + sorted (Red-Black tree, O(log n)). unordered_set = unique + hashed, unordered (avg O(1), worst O(n) on collisions).

#include <set>
set<int> s{1,2,3,4};
s.insert(10); s.erase(20);
if (s.find(20) != s.end()) cout << "found";
for (auto it=s.begin(); it!=s.end(); ++it) cout << *it << " ";
// NOTE: no s[i] — use iterators. s.end()==s.find(v) ⇒ absent. 1-arg find (vs 3-arg vector find).

#include <unordered_set>
unordered_set<string> u{"apple","banana","orange"};
u.insert("pear"); u.erase("banana");

Remove duplicates, keep order (from notes)

vector<int> dedup(vector<int>& nums){
  unordered_set<int> seen; vector<int> res;
  for (int x : nums) if (seen.insert(x).second) res.push_back(x);
  return res; // insert() → pair<it,bool>; .second==true ⇒ was new
}
unordered_set notes: hash-based order is arbitrary; load_factor (default 1.0) = elems/bucket; great for fast lookup / union / intersection; not for ordered iteration.

🧮 Bit Manipulation, Math & Geometry

num << 1;  // ×2  (5 << 1 → 10) — faster than *2 in contests
num >> 1;  // ÷2  (5 >> 1 → 2, fraction dropped)
1 << n;    // 2^n
__builtin_popcount(5); // → 2 (count of 1-bits)
(num & 1);  // LSB check: 5&1==1. 5=0101, 1=0001. Great for masking.
NOTE (fixed from notes): left-shift multiplies, right-shift divides — the original doc had the two examples swapped. Shifts beat multiply/divide in tight loops.
